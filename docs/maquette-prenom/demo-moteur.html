Le moteur de broderie

Une bibliothèque autonome, sans dépendance : broderie.js + broderie.css. Chaque effet est déclaré par un attribut data-broderie et s’active tout seul. Cette page les isole un par un, avec les réglages pour les voir dans tous leurs états.

1. Point de bourdon Alphabet 2. Le fil 3. Le tambour 4. Points de croix 5. Curseur aiguille Mesures Mouvement réduit

1 · Le prénom au point de bourdon

data-broderie="prenom" — le texte est remplacé par un SVG où le prénom s’écrit en points serrés perpendiculaires au tracé de la lettre, posés un par un. Le texte reste accessible (span visuellement masqué) et le tracé « crayon » très pâle est visible dès le premier rendu : rien n’est jamais invisible en attendant l’animation.

L’alphabet monolinéaire

Le contrôle qualité des glyphes. Aucune API navigateur ne donne le contour d’une police : les lettres sont dessinées ici comme des lignes médianes, que le moteur habille de points perpendiculaires — exactement la façon dont un logiciel de broderie machine travaille.

2 · Le fil qui relie les sections

data-broderie="fil" sur ce conteneur. Un fil sinueux le traverse et se brode au rythme du défilement, une aiguille en tête avec un léger balancement. Le fil passe derrière le contenu (couche en z-index: 0, enfants directs en z-index: 1) et se dé-brode si l’on remonte.

3 · Le tambour à broder

data-broderie="tambour" sur une <figure> contenant une <img>. Le cercle se serre à l’entrée dans l’écran, l’image se dévoile, le liseré de bois se dessine et la vis apparaît. Au survol : une très légère tension du tissu. Sans JavaScript, l’image reste une image rectangulaire normale.

4 · Les points de croix

data-broderie="croix" — une grille qui se remplit point par point dans un ordre légèrement aléatoire (la régularité mécanique trahirait la machine). Options : data-colonnes, data-lignes, data-motif (bande, vague, losange, coeur), data-fil, data-duree.

5 · Le curseur aiguille

data-broderie="aiguille-curseur" sur <body>. Activé uniquement si (pointer: fine) — jamais sur tactile, jamais en mouvement réduit. Le curseur natif reste visible sur les champs de saisie, où il porte une information. Il est actif sur toute cette page : bougez la souris.
